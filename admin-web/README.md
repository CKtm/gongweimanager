# 研究生工位管理系统（管理员端）

基于 Vue 3、Element Plus 和 Vite 的管理员端，用于研究生工位、工作室、分配、申请、退还、卫生检查及师生档案管理。

## 本地运行

```bash
npm install
npm run dev
```

开发环境默认通过 `/dev-api` 访问后端，请先在 IDEA 中启动管理服务（默认端口 `9090`）。

初始密码账号不会直接登录成功。账号密码校验通过后，登录页会使用5分钟有效的一次性票据强制修改密码；修改完成后必须使用新密码重新登录。该流程同时适用于管理员端和微信小程序。

## 正式构建

```bash
npm run build:prod
```

构建产物位于 `dist`。

## 保留模块

- 项目数据看板
- 工作室与工位台账
- 固定工位分配、流动工位两级审批与退还审核
- 卫生检查任务与记录
- 师生档案及导师关系
- 用户、角色、操作日志、登录日志

其他框架示例、监控、代码生成、字典和参数管理页面已从管理员端移除。
