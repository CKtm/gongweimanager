# 管理功能迁移对照

入口：管理员登录 → 首页“系统与基础配置”，或“管理员工作台 → 管理”。普通学生、导师、检查员不能进入管理配置页；管理员内部继续按原权限逐项展示和校验。

| 原 PC 功能 | 小程序入口与覆盖范围 |
| --- | --- |
| 流动工位申请管理 | 审批中心：终审、审批并分配、单独分配、审批历史 |
| 工作室申请管理 | 审批中心：通过、驳回、申请历史；房间管理：解除导师归属 |
| 退还回收 | 审批中心：照片预览、退回补拍、确认释放、兼容历史核验流程 |
| 分配台账 | 座位管理：固定分配、同类型调整、主动收回；管理：当前与已结束占用历史 |
| 房间管理 | 管理 → 房间：查询、新增、修改、正常/维修/停用状态、删除 |
| 工位管理 | 管理 → 工位：按房间/类型/状态筛选、新增、编号/布局行列修改、停用恢复、删除、Excel 导入；座位页按行列可视化 |
| 师生档案 | 管理 → 人员档案：查询、新增、编辑、身份与编号、导师绑定/解绑、批量初始化账号和师生关系 |
| 用户管理 | 管理 → 用户：分页、手机/账号/状态筛选、创建/编辑、角色/岗位、停用恢复、重置密码、删除、批量删除、导入/导出 |
| 角色管理 | 管理 → 角色：新增/编辑、标识/顺序/状态、功能菜单权限、成员授权/取消授权、删除、导出 |
| 登录日志 | 管理 → 登录日志：账号/IP/日期/状态查询、分页、详情、单条/批量删除、清空、导出、解除账号密码错误锁定 |
| 操作日志 | 管理 → 操作日志：模块/操作人/IP/日期/类型/状态查询、分页、详情、删除、清空、导出 |
| 卫生检查 | 检查：创建无预设范围任务、指定检查员与日期、查看整体/工位评分及照片、核实、归档 |
| 首页统计 | 工作台待办数；座位页工位总数、空闲、占用、回收中及使用率 |
| 个人中心 | 我的 → 编辑资料与头像：昵称、手机、邮箱、性别和头像；保留修改密码、退出登录 |

浏览器专属外壳（如网页锁屏、404 页面）不作为移动端业务功能复制。PC 源码保留，未停止原有服务或删除数据。

## Excel 操作

导入：打开对应管理列表 → 批量导入 → 下载模板 → 在手机支持 Excel 的应用中填写 → 将文件发送到微信聊天 → 选择聊天文件 → 确认导入。用户导入可选择是否更新已有账号；工位和业务档案沿用各自后端导入规则。

导出：点击导出 Excel，系统带当前查询条件请求原导出接口，在微信内打开文件，可通过文档菜单转发。导入结果采用纯文本显示，服务器错误不会被当成 Excel 保存。

## 权限与验收

组织机构树、部门列和部门选择控件已移除；底层历史关联和既有数据范围保留。新页面复用原有后端接口、角色和数据范围。没有权限的入口或操作不展示，后端仍进行最终授权；不因迁移自动给学院管理员增加系统权限。

已覆盖的自动化检查：

```sh
node tests/admin-management.test.cjs
node tests/admin-files.test.cjs
```

测试使用隔离的微信 API/HTTP 模拟，验证提交字段、权限拦截、分页、文件错误、菜单及既有权限范围保持、批量授权。它们不代表真实微信文件传输和真机输入已完成验收。

停用 PC 前请在微信开发者工具和真机上使用实际管理员账号，逐项完成上表验收，重点验证 Excel 文件选择/打开/转发、权限变更后重新登录、头像上传及删除业务关联校验。
